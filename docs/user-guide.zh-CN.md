# Gearhouse 使用说明

## 装备与活动

### 浏览与整理装备

装备树支持任意层级，可展开、收起、搜索和多选。当前类别与显示条件列在列表上方，点按可移除。装备支持新增、编辑、购买日期、退役、隐藏，以及添加新组件或已有装备。

调整位置时，先点按“编辑”，选择装备后点“调整所属装备”，也可点按行右侧的手柄选择目标。拖动手柄，在目标行高亮时松开，也能调整位置。选中多件后可整批操作，连续调整后统一保存。选择“设为顶层装备”或拖到“顶层装备”可解除所属关系；拆下备用则使用“拆下”放入库存。

编辑时可全选当前显示的装备。切换搜索或类别仍保留已选项，底部显示已选数量。使用最大两档辅助字号时，点按底部“操作”选择批量动作；已有待保存的层级修改时，点按“修改操作”撤销或保存。

保存时可选择“变更装配”并指定生效日期，或用“整理层级”修正同一根装备内的共同历史时段。删除装备后先进入回收站，可恢复；永久删除时需再次确认。

### 库存与更换

装备页可切换“使用中／库存”。库存按类别保留组件树，支持查找、类别筛选和新增待装装备。在“使用中”多选后可“放入库存”。没有上级的自行车、鞋和骑行台不会自动归入库存。批量入库时会列出所选日期已退役的装备，点按“移除已退役装备”可将其排除，其余装备继续入库。

同类别、同名称的独立库存装备合并显示为“名称 ×数量”，展开后逐件查看和操作。同名装备以数字区分，里程、历史和附件各自保留；装上一件后，其他件继续留在库存。整套装备及其子组件保持树形展示。

复制出的装备保留原名称并放入库存，可带上提醒规则。新装备从零累计，单独设置购买日期和装配。

“添加组件 → 已有装备”支持名称搜索和类别筛选，并显示库存／使用中状态及累计距离。切换搜索或类别保留已选装备，可跨类别多选。

组件详情右上角操作菜单或长按装备后的“更换”只允许同一类别的装备。可从库存选择，也可直接新建；新建类别固定为旧件类别。旧件默认放入库存，也可退役。整套组件可随旧件保留，或选择转装到新件。

装备详情右上角操作菜单中的“拆下”将组件放入库存；库存组件可“装到装备”，独立使用的装备可“取出使用”。装配目标已有同类别组件时，需明确选择替换哪一件或作为新增组件。每件实物保留自己的累计值、保养记录、提醒、图片和附件，装回后继续累计。

更换、入库、取出和装配可按日期记录，也可打开“记录具体时间”，按显示的上海时间及 UTC 偏移填写。旧的按日记录继续从当天开始生效，不会被推定为某个具体时刻。具体时刻相同的活动采用变更后的装配；活动的 UTC 开始时刻可用时，跨时区和夏令时回拨按绝对时刻判断。缺少可靠开始时刻且可能受具体换装时间影响时，组件归属标记为待核对，重算会跳过该活动；可同步完整活动后再预览重算。

更换历史可整体编辑或删除，相关装上、拆下和库存状态一起修改；同一时刻冲突或已有后续装配时需先处理原记录。已有活动快照保持原样，涉及过去活动时可预览重算。远端活动明确使用了当时在库存的主装备时，保留活动事实并提示核对使用日期。

### 类别与距离规则

在装备页菜单中选择“装备类别”，可新增或编辑类别，设置名称、基础类型和“计入室内骑行距离”。新增／编辑装备时也能直接创建类别。自定义类别保留基础类型的活动选择和 Intervals.icu 同步能力。

内置 23 类：自行车、跑鞋、锁鞋、锁片、锁踏、功率计、车把、坐垫、坐杆、牙盘、曲柄、盘爪、轮组、轮胎、内胎、来令片、碟片、飞轮、链条、前变速器、后变速器、骑行台、其他装备。“车轮”统一归入“轮组”，前后轮可用名称区分；“传动系统”不再是默认类别。

骑行台、链条、飞轮、牙盘、曲柄、盘爪和前后变速器默认计入室内骑行距离，其他类别默认关闭。规则只用于新活动和主动重算；修改类别不会重写已有活动。类别随完整备份保存。

### 历史、时间线与重算

装备详情按“历史／活动”切换，可增删改装配记录，添加保养／摔车／滴蜡／煮蜡等记录，或查看活动日期范围统计。历史仅显示本装备的记录，右侧“＋”可添加装配或记录。

点击“时间线”可查看本装备及当时所属组件的装配与维护记录。点按一条记录，会打开对应装备并定位到该记录；组件换车后，原车的时间线仍能查到此前的记录。时间线按月份分组，可按装备、记录内容或日期搜索，也可用空格组合多个条件。

装配按日期记录，从当天开始生效。同一件装备同一天以最后一次归属为准。已有带时刻的装配历史会自动转为整天；转换前保留原有数据，已有活动的装备归属和累计值保持原样，需要时可主动重算。历史快照按所选日期重建装备树和累计值，只读查看。

重算支持单件装备、装备与组件或整个类别，可选择日期范围、保留手动修改，并预览距离、时长、活动次数及装配变化。预览列出未完成同步的日期和不完整的活动；涉及导入的历史累计值时需明确确认。数据更新后需要重新预览才能应用。

### 活动关联与保存

活动按月份分组，可按名称、装备、组件、运动类型或日期搜索，也可用空格组合多个条件。日期可输入 `2026-10-12`。

右上角筛选菜单可选择运动类型，或只看“主装备未关联”“待确认或同步”的活动。筛选可以与搜索一起使用；点按列表上方的条件可单独清除，清除筛选时保留搜索词。月份标题旁的次数对应当前搜索和筛选结果。

活动列表显示主装备、锁鞋和骑行台。只修改锁鞋或骑行台会保留其他选择，主装备继续跟随 ICU；明确选择“无”会保留这次选择。

修改主装备后先保存到本机，再上传到 ICU 并回读确认。上传失败时会显示“本机已保存 · ICU 待同步”，可以稍后“上传到 ICU”。尚未保存时返回或取消修改，可选择继续编辑或放弃更改；已经保存到本机的选择不受影响。

ICU 主装备与本机选择冲突时，可“采用 ICU”或“采用本机”；上传前会再次核对。旧版手动指定继续保留，可通过“恢复跟随 ICU”解除主装备覆盖，锁鞋和骑行台仍然保留。

### 图片、附件与编辑草稿

装备、记录和活动均可添加图片。装备详情的图片按钮可添加或管理图片，点击封面可打开图库。支持封面、排序、浏览和删除。图库中可双指缩放、双击放大或还原；放大后可拖动查看，拖到左右边缘后再次滑动可翻页。

记录图片添加中可点按“取消添加”，保留原有图片和未保存的记录；清理完成后可继续编辑或重新选择图片。

装备详情的“附件”可保存发票、保修凭证和说明书，支持 PDF 与图片，每个文件不超过 20 MB。附件可直接预览、分享或删除，随完整备份保存。

编辑装备、组件、装配、记录、活动、提醒、类别或更换／入库配置后，点按“取消”可选择继续编辑或放弃更改；未保存的内容不会因下拉关闭表单而丢失。更换及入库的确认页可返回编辑，保留已填写的内容。

## 装备提醒

点按装备页右上角的铃铛，可集中查看所有装备的提醒。到期提醒列在“待处理”，缺少起点记录等问题列在“需要检查”；未到期、稍后提醒和已暂停或完成的事项分别分组。可以按提醒事项或装备名称搜索，点按一条提醒继续处理。

提醒页右上角“＋”可选择装备并添加提醒。选择装备时支持搜索，使用中和库存装备都可选择。

在装备详情右上角菜单选择“添加提醒”，填写事项，再选择“累计里程达到”“再使用”或“到指定日期”。“再使用”可设置距离、天数和开始计算的保养／装配记录，重复提醒可单独开启。也可以从一条保养记录的菜单直接添加，自动选中该记录。

提醒显示在装备详情，支持编辑、暂停、完成、明天提醒和删除。基于保养记录的重复提醒会随同类记录开始新周期；固定日期按原日程重复。组件换车不会丢失使用量。距离统计沿用已保存的活动快照和距离计入规则；隐藏装备继续提醒，退役和移入回收站暂停，永久删除时移除提醒。提醒随原生备份保存，通知授权需在新设备单独开启。

仅修改提醒事项时，保留已完成和稍后提醒的状态。修改距离、日期、起点或重复条件后，按新的条件重新计算。

距离和天数分别显示进度条，同时设置时，任一条件达到就会提醒。达到条件后显示橙色，并列出超出的距离或天数；指定日期的提醒显示日期和倒计时。记录对应的保养后，重复提醒开始下一周期。

首次创建提醒时请求系统通知权限。日期提醒由系统本地投递，距离提醒在活动同步或相关数据变化后检查；iOS 后台调度不能保证骑行结束立即通知。长期不打开应用时，后续重复提醒可能停止；重新打开应用可补充安排。

## 同步与数据

首次读取装备时包含 ICU components、装配关系和可用历史基数。以后同步会刷新可关联的 ICU 装备目录，装备编辑页也可手动刷新。目录变化不会重复创建本地装备，也不会覆盖本地名称、装配和历史累计值。活动中未关联的主装备可关联已有装备，或新建装备后关联。以后以本地装配为准，不回写装备树。

在“同步”页开启“自动同步”后，应用会在前台定期检查，后台通过 iOS App Refresh 请求机会；后台执行时间由系统决定，不能保证固定五分钟。打开应用后会补齐离线期间的数据，历史补录可选任意日期范围。

同步进行时可点按“取消同步”停止本次读取，已导入的活动保留。自动同步仍按原设置运行。

同步会更新活动数据及跟随 ICU 的主装备归属。只补鞋不会阻止后续主装备同步，也不会让无关组件的历史重算被跳过。列表中缺失的活动会逐条查询，只有 Intervals.icu 确认活动已不存在时，才标记删除并移除对应使用量。

新导入及重算的 Virtual Ride／骑行台活动按每件装备所属类别决定是否累计距离；室外活动正常累计。活动次数和时长继续保留。旧活动继续采用已保存的距离计入结果；在类别编辑页可对该类别的装备统一预览重算。

API Key 存入本机 Keychain，不包含在备份里。图片重新编码为有尺寸限制的 JPEG，去掉原始附带元数据。

## 备份与恢复

启动时若本机数据无法读取，可点按“重新读取”重试，或进入“备份与恢复”选择备份。恢复前会保留无法读取的数据文件；恢复成功后可继续使用装备和活动，同步前需重新连接 Intervals.icu。

在“同步 → 备份与恢复”开启“iCloud Drive 自动备份”，首次选择 iCloud Drive 中的文件夹。装备、库存状态、更换记录、装配历史、活动归属、保养记录、类别、提醒、图片和附件一起保存；连接密钥和通知权限不随备份恢复。

数据修改后自动生成版本，无变化时不重复备份。应用在前台时检查备份，后台执行机会由 iOS 决定；关闭应用后不保证立即产生新版本。只有 iCloud 确认文件上传后才显示为最近备份；上传失败会保留已有版本。

“恢复备份”可按时间选择版本并查看内容数量。恢复会替换本机数据，先检查文件和附件完整性。本机数据与文件完整时，会保存为可从列表选择的恢复前版本；图片或附件缺失时，保留现有数据和仍在本机的文件；无法读取的数据则保留原文件。本机账户可读取时，备份必须属于同一 Intervals.icu 账户。

有版本尚未下载完成或无法读取时，列表会保留其他可用版本和本机恢复前备份，可点按“重新读取备份”重试。

自动清理只在新版本上传并通过完整性检查后执行，保留最近 3 份，以及最近 7 天的每日版本和最近 4 周的每周版本。恢复前的本机版本独立保留。

“立即备份”和“选择备份文件夹”位于自动备份设置下方，“导出备份”和“导入备份”位于“备份文件”中。更换手机后，选择原 iCloud Drive 文件夹即可读取其中的版本；恢复数据后重新连接同一 Intervals.icu 账户。备份保存到所选文件夹里的 `Gearhouse Backups`。

准备导出或读取所选备份文件时可取消，完成准备后再选择保存位置或确认导入。JSON 备份文件必须小于 500 MB；图片和附件较多、无法导出为 JSON 时，请使用 iCloud Drive 自动备份。

## 从网页版迁移

在 Mac 上导出完整备份（只读访问 Gearhouse 数据库和图片，不读取连接凭据）：

```sh
python3 scripts/export-web-backup.py \
  --data-dir "$HOME/Library/Application Support/Gearhouse/data" \
  --output "$HOME/Desktop/Gearhouse-backup.json"
```

把文件发送到自己的 iPhone，在 Gearhouse“同步 → 备份与恢复 → 导入备份”中选择并确认。完整备份包含图片；网页版仅导出的图片索引 JSON 无法恢复缺少的图片文件。本机数据与文件完整时，导入前的版本可从“恢复备份”列表找回。导入后在手机重新输入同一 ICU 账户的 API Key。

已有原生版本的数据会自动迁移，迁移前保留旧格式的原文件。无法保留原文件时会停止迁移，可检查存储空间后重新读取。
